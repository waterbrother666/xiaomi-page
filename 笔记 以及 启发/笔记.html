默认值，所有子元素在一行内显示，不换行。 flex-wrap: wrap; 允许子元素换行，当一行放不下时，自动换到下一行。适用于设置多列布局。但是需要测量好外部容器的大小和子元素的大小，否则可能会出现布局问题。 flex-wrap: wrap-reverse; 允许子元素换行，但换行的方向与wrap相反，即从下往上换行。 14.flex-direction的使用 flex-direction属性用于指定flex容器中子元素的排列方向。常见的值包括： flex-direction: row; 默认值，子元素在水平方向从左到右排列。 flex-direction: row-reverse; 子元素在水平方向从右到左排列。 flex-direction: column; 子元素在垂直方向从上到下排列。适合设置图标在上文字在下的布局。 flex-direction: column-reverse; 子元素在垂直方向从下到上排列。 15.超链接的点击与height: 100%; 1.当一个元素被设置为超链接时，点击该元素会触发浏览器的默认行为，例如导航到链接的目标地址。 2.如果一个元素的height被设置为100%，它将尝试占满其父元素的高度。这可能会导致布局问题，特别是当父元素没有明确的高度时。 3.在某些情况下，如果一个超链接的height设置为100%，它可能会覆盖其他元素，导致无法点击其他内容。因此，在使用height: 100%时，需要确保父元素有明确的高度，并且不会干扰其他元素的交互。 4.但是他的优点是不用点到图标也能跳转对应网址 16.伪元素::before和::after的使用 1.伪元素::before和::after用于在元素的内容之前或之后插入内容。它们是虚拟的元素，不存在于HTML中，但可以通过CSS进行样式化。 2.语法： .element::before { content: "前置内容"; 下面可以设置内容的样式，例如颜色、字体、背景等。 } .element::after { content: "后置内容"; } 3.content属性用于指定要插入的内容，可以是文本、图片或空字符串。 4.伪元素可以用于创建装饰性效果，例如添加图标、背景、边框等，而不需要修改HTML结构。 5.注意：伪元素必须与content属性一起使用，否则它们将不会显示。 在父元素设置了position: relative;的情况下，子元素设置了position: absolute;，就可以使用top、left、right、bottom等属性来定位子元素的位置。 17.在不用表格的情况下给元素框之间加上边框--利用伪元素 18.从.channel ul li:nth-child(6)::after{ display: none;
