# 小米网页项目

本项目是以 **HTML5**、**CSS3** 和 **JavaScript** 开发的小米商城首页静态页面

## 已实现的交互功能

### 1. 丝滑轮播图 (Smooth Carousel)
* **淡入淡出效果**：利用 CSS `opacity` 与 `transition` 属性实现图片间的平滑过渡，避免了硬切带来的闪烁感。
* **手动控制**：通过左右箭头精确切换图片，并加入了边界处理逻辑。
* **图层优化**：采用绝对定位叠放图片，提升了动画性能并防止加载白屏。

### 2. 侧边分类菜单
* **悬停交互**：鼠标滑过一级菜单时，通过 JS 动态显示对应的二级商品详情面板。
* **层级管理**：合理设置 `z-index`，确保分类面板能完美悬浮在轮播图之上。

### 3. 搜索栏交互
* **状态反馈**：点击搜索框时，利用 CSS 选择器实现边框变色，提升用户体验。

### 4. 响应式布局
* **Flex 布局**：核心区域大量使用 Flexbox，确保了导航栏、副核心区（Channel）等模块的对齐精度与小米官方一致。
* **版心对齐**：严格遵循小米官方的 1226px 宽度标准。

##  技术栈
* **HTML5**: 基本结构。
* **CSS3**: 盒模型、Flex 布局、绝对定位。
* **JavaScript**: DOM 操作、事件监听。

## 项目结构说明
* `index.html`: 网页主入口。
* `css/`: 存放全局样式和局部模块样式。
* `js/`: 存放轮播图及侧边栏菜单交互逻辑。
* `images/`: 项目所需的静态资源。

## 不足
* `轮播`: 没有实现轮播的过渡切换以及自动切换
* `卡顿`: 轮播存在一定的卡顿
